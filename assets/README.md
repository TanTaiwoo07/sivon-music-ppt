# assets/

**此目录不收录实际素材图片与音频。**

演示所需的素材由各成员本地管理，不进入版本库。原因：

| 类型 | 问题 |
|---|---|
| 影视截图 | 版权状态不明，公开仓库有风险 |
| 人物肖像（含综艺、网络人物截图） | 肖像权 |
| AI 生成图（平台水印） | 部分平台条款限制再分发 |
| 《雨爱》司凤版音频 | 原曲版权 + AI 翻唱无授权 |

## 本地素材清单（仅记录用途，不记录文件）

| 槽位 | 用途 | 说明 |
|---|---|---|
| `p01-hero` | P1 主视觉 | AI 生成，音符/宇宙类，全屏出血 |
| `p02-meme` | P2 播放页小图 | 反应类梗图，1/4 幅 |
| `p03-triptych` | P3 三栏 | 三张同风格 AI 生成图，统一压暗 |
| `p04-reaction` | P4 反应梗 | 两张，斜置拍立得 |
| `p07-news` | P7 新闻截图 | GEMA 新闻页，保留日期 `31 JULY 2026` |
| `p08-filing` | P8 证据页 | 起诉书第 3 页，保留页脚案号 |
| `p09-dj` | P9 全幅 | 现场演出类图片 |
| `p10-half` | P10 半幅空镜 | 华丽但空洞的视觉，用于对比 |
| `audio-clip` | P2 音频 | 35s 司凤版 + 5s 原曲对照 |

## 使用约定

1. AI 生成的图在页面角落标注 `AI-generated (platform)`
2. 新闻截图保留完整标题与日期，不裁掉出处
3. 音频统一转 mp4 备份，避免现场播放器兼容问题
